# ESGA Basket — site web

Site HTML/CSS/JavaScript du club de basket de Genas.

Les informations publiques intégrées ont été vérifiées à partir de la Ville de Genas et de la FFBB.
Les données de catégories d'équipes correspondent à la fiche FFBB consultée pour la saison 2025-2026 et doivent être réactualisées pour 2026-2027 si le club publie une nouvelle composition.

## Pages
- `index.html` — Accueil
- `club.html` — Le club
- `equipes.html` — Nos équipes
- `matchs.html` — Matchs & calendrier
- `galerie.html` — Galerie
- `rejoindre.html` — Rejoindre le club
- `contact.html` — Contact

## Sources publiques utilisées
- Ville de Genas — vie associative
- FFBB — fiche du club et équipes

Les photos et le logo ne sont volontairement pas inclus : ils pourront être ajoutés dans `images/` lorsque tu les auras.
